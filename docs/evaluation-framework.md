# 学生综合素质评价体系框架 v1.0

> 本文档是 Student OS 评价体系的说明。体系的唯一配置来源是 [`src/core/framework.ts`](../src/core/framework.ts)，待办规则阈值在 [`src/core/recommendations.ts`](../src/core/recommendations.ts)。修改配置后，系统中的雷达图、得分、等级与待办会同步变化。

## 1. 设计依据

- 《深化新时代教育评价改革总体方案》（中共中央、国务院，2020）：改进结果评价，强化过程评价，探索增值评价，健全综合评价
- 《关于加强和改进普通高中学生综合素质评价的意见》（教育部，2014）：思想品德、学业水平、身心健康、艺术素养、社会实践五方面
- 《中国学生发展核心素养》（2016）：在五方面基础上补充「实践创新」，形成第六维度「创新素养」
- 《国家学生体质健康标准（2014 年修订）》：体质健康指标的数据来源

## 2. 评价原则

| 原则 | 说明 |
| --- | --- |
| 结果与过程并重 | 既看考试结果，也记录日常写实与成长过程 |
| 多主体参与 | 自评、互评、师评按权重融合，减少单一评价偏差 |
| 增值导向 | 关注学生相对自身的进步趋势，而不仅是横向排名 |
| 以评促改 | 评价结果自动转化为可执行的提升待办，形成闭环 |

数据来源说明：

- **系统计算**：由成绩数据自动计算，无需人工录入
- **写实记录**：客观记录（体测分、服务时长、获奖等）由学校折算为 0–100 分
- **多主体评价**：自评、互评、师评分别打分（0–100），按主体权重融合

## 4. 评价主体

| 主体 | 权重 |
| --- | --- |
| 自评 | 20% |
| 互评 | 20% |
| 师评 | 60% |

某一主体缺失时不参与计算，其余主体权重按比例归一。例如只有自评 90、师评 70 时：(90×0.2 + 70×0.6) ÷ 0.8 = 75。

## 5. 等级标准

| 等级 | 分数区间 | 含义 |
| --- | --- | --- |
| A 优秀 | ≥ 85 | 表现突出，可作为同伴示范 |
| B 良好 | 75–84.9 | 整体达标，个别方面仍有提升空间 |
| C 合格 | 60–74.9 | 达到基本要求，需要有针对性地改进 |
| D 待提升 | < 60 | 尚未达到基本要求，需优先干预 |

## 6. 计算模型

```text
得分率   = 分数 ÷ 满分 × 100%
指标分   = Σ(主体权重 × 主体评分) ÷ Σ有效主体权重        （写实记录类直接取 0–100 折算分）
学科成绩 = 各学科平均得分率的均值
学科均衡 = 100 − 2 × 各学科平均得分率的标准差（总体标准差，结果限制在 0–100）
维度分   = Σ(指标权重 × 指标分) ÷ Σ有效指标权重
综合分   = Σ(维度权重 × 维度分) ÷ Σ有效维度权重
覆盖率   = 已有数据的指标综合权重之和
```

缺失数据一律不计入、按剩余权重归一，并通过「评价覆盖率」显示数据完整程度；雷达图上缺失的维度不画顶点，避免把「未评价」误读为 0 分。

## 7. 成绩区间统计

对每名学生的每门学科，在所选考试范围内统计：

| 统计量 | 说明 |
| --- | --- |
| 最高分 / 最低分 | 并注明出现在哪次考试（并列时取最近一次） |
| 平均分 | 算术平均 |
| 极差 | 最高分 − 最低分 |
| 标准差 | 总体标准差，衡量发挥稳定性 |
| 趋势 | 按考试先后对得分率做最小二乘拟合的斜率（百分点 / 次） |

不同满分的学科（语数英 150、其余 100）统一换算为得分率后比较。班级视角下统计单次考试全班各科的最高、最低、平均分，以及本人名次（并列同名次）。

## 8. 提升待办生成规则

评价结果按以下规则转化为待办。同一学科的多个信号合并为一条待办，优先级取最高者。

| 触发条件 | 优先级 |
| --- | --- |
| 学科平均得分率 < 60% | P0 紧急 |
| 学科平均得分率 < 70% | P1 重要 |
| 近 3 次及以上考试得分率平均每次下滑 ≥ 2 个百分点 | P1 重要 |
| 最近一次考试未达合格线（平均已合格时） | P1 重要 |
| 低于班级平均 > 5 个百分点 | P1 重要 |
| 得分率标准差 ≥ 8（发挥不稳定） | P2 持续 |
| 同一学科叠加 2 个及以上 P1 信号 | 升级为 P0 |
| 最强与最弱学科得分率差距 ≥ 20 个百分点（偏科） | P1 重要 |
| 素质指标 < 60 分 | P0 紧急 |
| 素质指标 < 75 分，且所属维度 < 75 分 | P1 重要 |
| 最强学科得分率 ≥ 85%（优势保持） | P2 持续 |

聚焦原则：每个维度最多生成 2 条指标待办（取最弱的两项）；维度整体达标时，只对不合格（< 60）的指标生成待办。

每条待办包含：

- **为什么**：触发原因与数据依据
- **怎么做**：学科或指标对应的行动清单
- **目标**：可量化的下一阶段目标（如「下次考试达到 70 分」「下一评价周期达到 75 分」）
- **时限**：P0 两周内启动，P1 本月内完成，P2 本学期坚持

## 9. 评价流程

每学期为一个评价周期：

1. **写实记录**：学生与教师持续记录活动、成果与表现
2. **整理遴选**：学期末遴选代表性材料，系统汇总成绩数据
3. **公示审核**：评价结果班级公示，接受申诉与复核
4. **形成档案**：生成综合素质档案与雷达画像
5. **反馈改进**：依据薄弱项自动生成提升待办，跟踪完成情况
